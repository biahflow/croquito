# Artefatos de feature

Status: Accepted
Responsável: Engineering / Product
Última revisão: 2026-08-17

Este diretório recebe somente artefatos de trabalho futuro selecionado por humano. A
convenção, lifecycle, responsabilidades e perfis de validação estão no
[Project Context](../engineering/PROJECT_CONTEXT.md).

Para cada feature, crie `docs/features/<feature-id>/feature.md` a partir do template
global da Engineering OS. Depois de um plano válido, registre `plan.md`, os Task Contracts
necessários e `evidence.md`. Não converta retrospectivamente marcos já concluídos, nem
crie uma feature sem seleção humana no roadmap canônico.
