# Glossário

Status: Accepted  
Responsável: Product / Engineering  
Última revisão: 2026-08-10

| Termo | Definição canônica |
|---|---|
| Aprovação | Congelamento explícito de uma `SceneRevision` pelo usuário. |
| `approximate` | Geometria estimada da imagem e aceita como não exata. |
| Bounding box | Retângulo normalizado que localiza evidência na página. |
| Constraint | Regra geométrica como distância, coincidência ou perpendicularidade. |
| Cota | Anotação que atribui dimensão, raio, altura ou distância. |
| `derived` | Geometria calculada de medidas e constraints confirmadas. |
| DXF | Formato de intercâmbio CAD; saída oficial do MVP. |
| Entidade | Objeto geométrico ou textual do scene graph. |
| `exact` | Geometria determinada por cotas suficientes e confirmadas. |
| Golden case | Exemplo com gabarito e DXF aprovados por revisor do domínio. |
| HITL | Human in the Loop; revisão humana das ambiguidades. |
| Issue | Problema estruturado com severidade, evidência e alvos. |
| Planta principal | Desenho que define o sistema espacial principal de uma página/projeto. |
| Prompt contract | Instrução versionada, schema e invariantes de uma chamada de IA. |
| Provenance | Origem rastreável de medida, entidade, constraint ou decisão. |
| Reanálise regional | Nova leitura de um recorte, sem repetir a página inteira. |
| Scene graph | Modelo canônico entre extração, revisão e exportação. |
| Subdeterminado | Problema com informações insuficientes para solução geométrica única. |
| Textract | OCR auxiliar; nunca autoridade geométrica. |
| `unresolved` | Entidade ou medida que exige informação/decisão antes da aprovação. |
